## 目标与约束

采用明确分栏、共用列线、稳定选择状态、整行展开入口和短过渡。保留原蓝灰配色、深色主题和现有业务，仅验收1920×1080，不增加WebGL依赖。

前一轮只补发送选项对齐，不能代替本次检查。此次先保存源码和修复前截图，再从常态、展开、选中/悬停、禁用、错误、长内容、空结果、键盘焦点逐项检查。测试中的账号、邮箱、名单、模板、二维码均为合成数据。

## 已确认问题与处理

| 范围 | 证据/原因 | 本次处理 |
| --- | --- | --- |
| 群列表选中悬停 | hover选择器优先级高于selected；深色截图中选中底色变成普通hover | 显式保留selected底色，同时保留原选中边框和标记；两种主题读取实际渲染颜色回归 |
| 写信模式栏 | sticky位于同一滚动容器，内容从圆角、顶边周围露出 | WorkbenchLayout增加可选sidebarHeader，模式栏与滚动aside分开，固定栏头预留相同滚动条槽，使左右列线一致；使用固定布局空间而非覆盖层 |
| 账号表单 | 修复前真实测量input高37px、select高39px，同排端口与加密下划线相差2px | 同一表单全部40px和20px行高，同排同高度；保留参数、校验、凭据门禁 |
| 搜索 | 模板搜索额外内外padding形成55px，其他搜索约38px，出现清除按钮时不统一 | 群、成员、模板、历史、待核实及手动排除的搜索统一40px，输入与清除按钮保持独立命中区 |
| 待核实卡片 | 32px复选区、gap与flex-basis总宽超过可用宽度；截图中复选框单独占一行 | 显式32px复选列+自适应详情列，核实/确认区在第二列，文字和复选框同排 |
| 模板长文本 | 一个长名称把同排卡片撑高，普通模板需要更多滚动 | 名称、主题各两行摘要，完整文本继续在DOM、悬停title和预览中；预览与导出选择仍独立 |
| 数据表格 | 顶部对齐使文字与36px行操作不在同一中心线 | 成员、历史和手动排除行垂直居中，常规操作行约56px；长文本仍自然换行 |
| 折叠与焦点 | summary点击区偏向文字；可聚焦滚动区缺少清楚的焦点提示 | 原生summary整行可点、右侧箭头统一；滚动区使用内描边，避免被overflow裁掉 |
| 禁用反馈 | 正文格式/预览、模板导出选择的hover没有排除disabled | 禁用时不出现可操作的悬停底色；原业务disabled条件不变 |
| 顶部日志异常图标 | 硬编码浅黄覆盖语义warning，浅色下不清晰 | 使用现有warning令牌，自动匹配两种主题 |
| 扫码弹窗 | 图标/关闭一行、正式标题另一行，通知宿主插在图标行后，导致通知跑到标题上方 | 正式标题与关闭按钮同排，删除重复图标行及无用样式；通知位于正式标题之后 |

修复前截图位于 `artifacts/detail-polish-before/`；修复后22张细节截图位于 `artifacts/frontend/detail-*.png`。没有将截图测试通过解释成所有潜在问题均不存在。

## 文件与兼容性

- `frontend/workbench.css`：集中维护布局、尺寸、选中/焦点/展开状态及动效令牌。
- `frontend/components/WorkbenchLayout.tsx`：增加可选固定栏头；保持原aside名称、tabIndex和滚动类名，不接管业务状态。
- `frontend/components/MailComposer.tsx`：模式栏传入sidebarHeader，事件处理器与原编辑器实例保留。
- `frontend/components/MailTemplateDialog.tsx`：完整名称/主题title与摘要说明注释。
- `frontend/App.tsx`：扫码弹窗标题合并到关闭行，保持原id、aria名称、二维码状态及轮询事件。
- `frontend/styles.css`、`frontend/mail.css`：日志颜色与扫码标题样式、删除无用图标样式、禁用hover修正。
- `frontend/tests/ui-check.mjs`：新增detail-layout聚焦入口和detail-polish完整入口；本轮全部尺寸强制1920×1080。
- README、使用说明、架构方案与本文同步更新当前包路径、布局、动效、测试入口与回滚说明。

没有更改Rust、数据库/配置/IPC/邮件协议、随机均分、共享历史/排除、冷却/等待时序、模板包格式或依赖锁文件；不需要迁移。Java/MyBatis专属规范不适用于React/TS/CSS/Rust，通用格式、注释和异常约束按项目执行。

动效只使用原生CSS、既有主题令牌；没有动画库、业务定时器、WebGL画布或额外挂载。入口动画只改变opacity，不改变表单和按钮几何，不延迟事件；减少动态效果时过渡时长归零、入口animation为none。模板摘要不修改任何存储/导出文本。公开新增属性sidebarHeader注释与使用说明同步。
