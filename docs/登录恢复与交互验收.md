本轮在已交付的快捷发送、手动排除和模板功能上增量修改；没有清理或重建用户数据，也没有关闭正在运行的旧程序。用户要求修复重启后的登录恢复，并检查所有模块的操作便利性、补充多选批量操作。

只读日志显示，2026-11-06 10:27:09（北京时间）本地登录文件恢复成功，随后群接口联网认证失败，旧流程立即删除了保存文件。这证明本次发生在联网校验之后，不是 EXE 更换目录导致找不到文件。旧日志未记录远端业务码，不能据此认定某个具体业务码或解释接口为何拒绝旧凭据；本轮不会宣称已证明 QQ 服务端可以持续接受七天。

## 登录恢复与兼容

- 保持应用标识、数据目录、`QQSESSION1` 格式、密文版本和 Windows 当前用户 DPAPI purpose 不变；SQLite 仍为 schema 3，无数据库迁移或清库。
- 明确远端认证拒绝时，最多补一次现有受控 HTTPS 成员页访问，再完整核对原账号与群列表，整个恢复仍受 35 秒预算限制。网络、权限、本地过期、时钟或账号变化不触发反复请求。
- 远端拒绝或网络失败保留加密文件，撤下内存连接、账号和群，进入可重试状态；群刷新、成员获取与启动恢复采用同一分类。未核验身份不能读取群或好友。
- 本地确已满七天、内容损坏或格式不兼容时清理；时钟回退提示校时并保留文件。重启、刷新和恢复不延长原扫码截止时间。
- 提供“重试恢复登录”和“清除保存的登录”；主动退出仍删除保存文件。重新扫码只有在身份验证成功后才替换原有凭据。
- 同一已核验会话的 Cookie 更新保存失败时，保留原密文和原截止时间；新扫码提交失败仍清旧身份，防止重启恢复错账号。没有保存文件时明确提示重启需扫码，不声称已经保留。
- 内部 IPC 的 `SessionView` 增加 `persistenceWarning` 布尔字段，普通状态默认 false，保存失败为 true；前端兼容缺省值。保存故障与登录权限分别表示，即使仍有原截止时间也能显示警告，不影响既有命令参数、SQLite 或密文格式。
- 补充固定恢复阶段、整数业务码及错误分类日志；不记录 Cookie、令牌、账号值或接口原始响应。

升级前结束或停止旧任务并退出旧版，备份完整 `%LOCALAPPDATA%/com.ahui.qq-group-exporter` 后再启动新包。不要同时运行不同版本；单实例会唤回已有旧进程，不会热更新。回退本轮修改无需迁移 SQLite，但旧版仍会采用原有认证失败清理策略；跨 schema 版本回退继续遵循此前完整备份说明。

## 全模块交互检查

| 模块/组件 | 检查与处理 |
| --- | --- |
| 主工作区与导航（App） | 初始化失败提供就地重载，清理旧订阅，避免迟到读取覆盖实时状态；不重挂写信组件或清空草稿。群和成员搜索可一键清除并恢复焦点；同一会话保存故障独立提示。检查账号隔离、切群版本、取消获取、导出取消、原名单保留和页面返回。 |
| 成员选择（MemberMailActions、成员表） | 新增跨页全选成员/搜索结果与取消全选；取消当前范围保留隐藏已选，可单独清空全部。表头明确本页范围，未知状态、待核实、读取失败和过期排除版本不能借批量入口选入。忽略键盘自动重复，行内按钮与拖选文字不误选。 |
| 排除群（FilterOptions） | 全选/取消当前搜索结果，保留隐藏已选；独立清空全部选择。显示当前匹配与已选数量；空、无匹配、加载和任务锁定状态清楚。 |
| 手动排除（ManualExclusionsPage） | 跨页全选当前结果、取消当前结果和全清；本页表头半选态；提示搜索外已选数量，一键清除搜索。搜索或翻页撤销旧移除确认，提交时锁翻页，取消不改变数据。保留添加输入、失败重试和全局规则语义。 |
| 历史维护（HistoryPage） | 明确全部待核实/本页范围；增加待核实独立搜索、匹配结果全选和取消，保留范围外选择并显示数量。清除搜索恢复焦点；搜索、翻页取消旧确认。整行、空格和 Enter 选择避开行内按钮、确认区、文字拖选和自动重复；批量提交门闩、失败保留与刷新恢复继续生效。 |
| 写信/配置/发送（MailComposer） | 发送状态初始化失败提供独立重试，只恢复监听与状态，不重读配置或覆盖内容；清理部分订阅。保存配置、清除授权码和停止发送补同步门闩；格式工具栏保留有效正文选区。手工邮箱支持全选输入，仅作用于当前发送模式；模板名称可 Enter 保存并排除中文输入法选词。检查快捷/群模式、图片、附件、预览、确认、失败继续及倒计时。 |
| 群收件人（GroupAudiencePanel） | 同一名单版本派生更新保留搜索与分页；搜索可随时清除并回到搜索框；真实未选择收件人与无匹配分开提示。 |
| 模板管理（MailTemplateDialog） | 加载失败不误报没有模板；显示匹配/总数量，随时清除搜索并恢复焦点。重命名/复制名称可 Enter 提交，中文选词不提交，删除保留明确确认。检查保存、更新、取消与应用内容替换边界。 |
| 范围替换（AudienceReplaceDialog） | 旧/新来源补群号辨认，同名群也可区分；默认焦点保留原范围。检查明确确认、Esc/取消一致、人数与内容附件保留。 |
| 日志（LogViewerDialog） | 增加全选当前只读日志便于复制。检查加载、失败重试、刷新门闩、关闭与目录入口；沿用固定只读范围，没有新增自动轮询。 |
| 浮层/主题（FeedbackHost、notify、theme） | 检查模态层级、关闭、去重、焦点、深浅主题及系统主题；沿用统一语义色和尺寸。 |
| 后台任务边界 | 检查导出取消不报失败、名单版本/排除版本校验、获取和发信停止；通用忙碌提示改为适用于所有调用方的“正在获取成员，请先取消或等待完成”。 |

没有给单选群切换、单选模板、外观选项或只读收件人预览强加全选。批量动作只处理明确显示的范围；发送仍须经过现有预检和二次确认，不因预览、应用模板、重试状态或维护记录而发送。

## 限制

本轮没有读取或解密用户保存的凭据、操作用户数据库、请求真实 QQ 或发送真实邮件。合成测试验证恢复策略、状态边界和资源流程，不能代替真实 QQ 恢复、七天持续有效或真实 SMTP 接受/送达证明。浏览器验收不替代原生标题栏、系统剪贴板/文件框、WebView2 缺失或无开发环境机器实测。

沿用现有依赖，没有新增常驻服务或恢复此前已移除的连接功能。注释、README、使用说明、方案与本验收记录同步；第三方声明无新增依赖条目。项目为 Rust/TypeScript，Java 手册语言专属条款不适用；按项目约定采用通用注释、异常、测试、编码与敏感数据保护规范。
