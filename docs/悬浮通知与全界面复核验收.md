# 悬浮通知与全界面复核验收

作者：ahui。日期：2026-11-13。验收分辨率仅1920×1080。

## 问题、根因与验收标准

用户截图中提示偏右、关闭键浮在卡片外，出现后整页下移。旧实现将通知作为普通flex子项占位；同时自定义定位/关闭样式与Sonner运行时插入的同优先级规则冲突。此前“通知不与任何控件重叠”的旧测试反而认可占位栏，没有检查实际工作区位移，现已替换。

新增几何回归先在旧实现上失败并留证：工作区顶部由96px变为170.5px，下移74.5px；提示中心为1520px，关闭键不在卡片内。修复后的22个记录状态中，工作区/弹窗区域出现前后坐标完全一致，提示中心为960px，关闭命中正确。证据为 `artifacts/frontend/floating-feedback-before.json`、`floating-feedback-after.json` 和 `artifacts/floating-feedback-comparison.jpg`。

用户随后指出文字上、下留白不等。新增断言在修复前再次失败：56px卡片内文字上方13px、下方23.5px。原因是最小高度搭配flex-start，多余空间全留在下方，图标另有3px偏移。改为垂直居中并清除图标纵向偏移后，20个短提示样本的上、下留白均为18.25px，图标与文字中线差为0。证据为 `artifacts/frontend/floating-feedback-vertical-before.json` 和 `artifacts/floating-feedback-spacing.jpg`；此项已同时覆盖最终生产资源。

## 修改范围与交互结果

- `frontend/components/FeedbackHost.tsx`：保留一个Toaster和原生dialog portal，宿主附在应用或最上层弹窗末尾。移除插入普通布局行的逻辑，不重建通知、草稿或任务。
- `frontend/styles.css`：固定悬浮宿主，列表顶部居中；普通页面避开主导航，模态中浮在视口顶部。显式app-toaster/app-toast规则抵抗第三方后插CSS。卡片宽560px、最小高56px，文字/图标垂直居中；32px关闭键在卡片内。最多3条，正文超长在120px高区域内滚动；宿主外部不拦截点击，退出/不可见条目不留透明点击区。进入160ms、退出120ms，减少动态效果时关闭过渡。
- `frontend/lib/notify.ts`：生产资源复核另发现“刚关闭又出现同文提示”会被旧卡片200ms延迟卸载误删。现只对尚未关闭的同文提示复用ID，关闭/超时立即释放登记，重新出现使用新ID；旧回调只释放自身登记。4秒普通/成功、7秒错误、悬停暂停、去重和键盘关闭保留，不修改第三方依赖。
- `frontend/components/DialogLayout.tsx`：同步悬浮宿主位置注释；三段式正文滚动/固定底栏保持原行为。
- `frontend/tests/floating-feedback-check.mjs`、`ui-check.mjs`：替换错误的占位验收，新增生产资源入口。检查真实矩形、上下留白、图标中线、关闭命中、样式插入顺序、长文/多条、外部点击、原生/双层弹窗、滚动、键盘、焦点保持、去重、立即重复、自动收起和减少动态效果。

复核模块分栏、字段对齐和层次；保留应用蓝灰白/深色配色与桌面数据密度。人工查看了成员空态/展开/结果、写信参数、账号表单、长/空模板、待核实记录、手动排除、扫码和悬浮反馈截图。已有搜索40px、账号40px、发送参数36px、选中悬停、模式固定栏、固定页脚等细节保持；没有为营销效果添加3D画布或动画依赖。概览见 `artifacts/floating-feedback-overview.jpg`，最终24张全高清浮层/生产截图尺寸见 `artifacts/floating-feedback-screenshots.json`。

App、MailComposer、MailTemplateDialog、SenderAccountsDialog、HistoryPage、ManualExclusionsPage六个业务组件与本轮源码基线逐字节一致。未变更Rust业务代码、数据库、IPC、配置默认值、账号分配、共享历史/排除、等待/冷却或模板包格式，不需要数据迁移。Java/MyBatis专属规则不适用于本项目的React/TypeScript/CSS，通用格式、注释、异常和编码规则按项目执行。

README、使用说明、架构方案、组件注释已同步。此前两份验收记录已明确标记占位通知方案被本记录替代，保留历史事实。前端/README/使用说明/新文档为UTF-8无BOM/LF；架构方案保留UTF-8无BOM/CRLF。
