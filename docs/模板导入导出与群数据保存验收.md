## 需求、原状与改动

本轮接续登录恢复和选择便利性优化，新增邮件模板导入/导出，并补齐群目录及每群最新成员数据的 SQLite 持久化。原来模板只能在本机维护；成员结果虽已落库，但全局只保留最近 20 份快照，较早获取的群可能失去对应结果，群目录仅在内存。

模板入口为“写邮件 → 选择模板”。支持导出当前模板、多选导出、按搜索结果全选/取消和清空导出选择；搜索范围外已选项保留。导入先预览模板、主题、图片和附件数量，再选择另存副本、跳过同名或覆盖。默认副本，覆盖本机同名项须额外确认；存在源包重名或本机同名歧义时禁止覆盖。导入仅更新模板库，不应用当前草稿、不改变收件人、不发送邮件。

群目录在成功扫码、恢复登录、刷新列表后按来源和账号原子保存。点击“获取成员”仍重新联网读取，成功后同一事务保存历史、更新该账号该群的最新名单及群元信息；新结果整体替换成员及资料，不是只追加。失败、取消或被废弃的任务不覆盖旧结果。不完整或待核验结果仍保留对应状态，不因保存而变成完整名单。

每个来源/账号/群独立保留一份最新结果，另外保留全局最近 20 份历史。每群最新不受其他群的历史淘汰影响，固定版本导出和邮件资格校验可读取两处记录；版本两处都不再保留时要求重新确认。实时更新按成功提交顺序，不依赖电脑时间或随机 ID 排序，已覆盖同刻获取和时钟回拨。群目录是历史记录，不作为已登录或仍有群权限的证明；本轮没有新增离线账号选择或自动采集所有群的功能。

成员仍保存在既有 Snapshot JSON 中，含最终成员、已过滤成员、QQ 号、昵称、名片、关系及核验/筛选结果，不另建重复成员表。仅获取目标群时保存该群完整结果；作为排除条件读取的其他群保留既有摘要，不新增其完整成员副本。完整好友表、QQ Cookie 和 SMTP 授权码不进入 SQLite。

## 数据格式与兼容

模板包扩展名 `.qqmailtemplates`，UTF-8 无 BOM JSON，根格式 `kind=qq-mail-templates`、`version=1`。包内包含名称、主题、HTML 及 Base64 编码的实际图片/附件字节，可跨电脑导入，不依赖旧路径；不包含本机模板 ID、收件人、QQ 登录或 SMTP 设置。各层拒绝未知字段，图片真实内容、数量/尺寸与 CID 继续按现有规则核验。文件最大 128 MiB，正文和解码资源合计最大 80 MiB，最多 200 份，单模板仍受原有 18 MiB 资源等限制，超限需分批。

同名按去掉两端空白后的完整名称精确比较，区分大小写。副本自动生成唯一名称；跳过也处理同包先前出现的同名项；覆盖保留目标 ID 和创建时间，整体替换内容和资源。预览仅保留一个包，5 分钟后失效；目录变更要求重新选择。提交在 IMMEDIATE 事务中重核目录，任一失败整批回滚；可恢复的数据库失败保留预览供重试。导出通过同目录临时文件 flush/sync 后原子替换，原生取消不报成功。包内是实际邮件内容，应按内容备份保存。

数据库仍位于 `%LOCALAPPDATA%/com.ahui.qq-group-exporter/data.sqlite3`，与 EXE 所在目录无关。schema 4 新增 `account_group_catalog` 和 `latest_group_results`，旧 0/1/2/3 库同事务升级并从尚存快照回填；此前已淘汰的成员不可恢复。每群最新和最近 20 份历史可能存有同份结果的独立副本，磁盘占用随已获取群的数量/规模增长，不保留无限历史版本。

升级前退出程序，备份整个数据目录及可能存在的 WAL 文件。升级失败回滚表、回填与版本号。旧程序拒绝 schema 4；回退需保留新库另存，再恢复升级前完整数据目录备份，不能只降低 `user_version`。本轮没有读取、升级或备份用户真实数据库，所有迁移回归使用临时合成数据库。
