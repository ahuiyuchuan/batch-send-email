# batch-send-email v1.0.0

首次正式开源发布。统一项目名称与GPL-3.0-only协议，新增关于页和正式Release更新检查；保留多群合并、名单筛选、多账号发送、模板交换、共享历史／排除及本机保存流程。

## 新功能与交互

### 关于与更新

- 关于页展示软件名称、当前版本、Windows x64免安装模式、GPL-3.0-only和作者；软件信息、版本更新、项目与反馈、本版功能保持原有纵向卡片布局。项目入口包括GitHub项目、发布记录和问题反馈。项目协议、第三方说明与许可合订本作为`licenses/`文本资源随EXE嵌入，原文和对应源码保留在仓库及同版本Tag。
- 启动与每小时静默检查本项目GitHub正式Release，手动入口显示正在检查、失败可重试、尚无正式发布、当前已是最新版或发现新版，并记录检查时间；发现新版展示发布说明和前往下载入口。
- 检查只访问公开发布信息，不上传群聊、成员、邮箱、正文或凭据；与获取／发送任务隔离，不自动下载、安装或覆盖程序。网络错误不能冒充最新版本，重复检查共用后端门禁。

### 名单与写信

- 目标群复选框支持跨搜索选择、全选当前结果和清空，每次最多200个。逐群核验后按QQ号合并去重，来源详情保留各群人数和状态；任一读取失败或取消保留旧结果，不发布半套名单。
- 排除群、QQ好友、已发送和全局手动排除作用于同一并集，重复成员只计一人和首次原因。单群／组合最新快照独立保存，导出Excel／CSV／TXT与固定邮件范围使用同一名单版本。
- 多SMTP账号默认随机均分，候选人数最多相差1；预检应用共享历史与排除后冻结计划。逐人或密送分批、同账号冷却、账号切换等待、单次跳过和停止继续保留，默认同账号900秒、切换60秒。
- 确认发送前的预计结束日期时间随当前时刻刷新，确认后由运行进度接管；发送记录保留原发件账号，结果不明确的投递须人工核实，不自动重发。
- 模板支持正文／图片／附件副本、预览应用、管理及JSON导入导出；跨页操作保留草稿，明确更换成员范围才替换邮件候选。发送选项与账号隔离名单筛选记住上次合法选择。

### 页面与发布一致性

- 保留原蓝灰配色及深浅主题；关于页沿用纵向信息卡片，状态反馈清晰，底部更新操作固定可见。
- 列表按数字自然序、中英文首字母同级排序，批量操作明确搜索范围；顶部悬浮提示不挤动布局，长弹窗操作固定底部。
- npm／Cargo／Tauri版本统一1.0.0，Tag采用`v1.0.0`，Release仅交付单个带版本的Windows x64 EXE；README、CHANGELOG、使用及贡献指南同步。

## 使用与升级

- Windows 10/11 x64：[下载单个EXE](https://github.com/ahuiyuchuan/batch-send-email/releases/download/v1.0.0/Batch-Send-Email-v1.0.0-Windows-x64.exe)，需要系统WebView2 Runtime。完全退出旧版后运行新版，GitHub自动生成的Source code归档不是可执行程序。
- 本版改名继续使用既有`com.ahui.qq-group-exporter`标识和`%LOCALAPPDATA%/com.ahui.qq-group-exporter/`数据目录，不搬迁、不清空SQLite或凭据；schema保持5，旧单群快照可读，多群来源JSON为可选增量。
- 升级前退出并备份完整应用数据目录。SMTP授权码受Windows用户与设备绑定，密文不能直接移植；QQ登录只保留当前进程，重新启动需扫码。
- 合并名单超过10000人仍可查看和完整导出；单次写信保持10000人上限，应先勾选部分成员。SMTP接受不保证收件箱送达，默认间隔不代表服务商许可，多账号均分不代替额度与风控要求。
- 回退测试版须退出当前进程；旧版没有关于／更新或多群入口时会忽略相应新字段。如需回到升级前完整状态，应恢复原先备份的整个数据目录，不删除数据库或降低schema号。
