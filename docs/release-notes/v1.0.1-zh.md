# batch-send-email v1.0.1

修复 [#1：不能插入链接](https://github.com/ahuiyuchuan/batch-send-email/issues/1)。写邮件现在可以把“查看详情”等文字设为可点击链接，并在模板及实际邮件中保留目标地址。

## 修复与交互

- 工具栏新增“链接”，正文内可按 Ctrl+K。选中文字后填写地址；没有选字时插入到光标处，显示文字留空则使用地址。
- 光标放入已有链接即可编辑；“移除链接”保留文字和基础格式。取消或 Esc 保留正文与选区，链接操作支持撤销，继续输入不会延长刚插入的链接。
- 错误地址在字段下提示并保留输入，中文输入法确认候选不会误提交；跨段落、图片或多条链接混选时提示重新选择，不破坏内容。弹窗沿用原配色，标题和底部操作保持可见。
- 模板保存、应用、导入导出保留合法文本链接。HTML 邮件保留可点击链接，纯文本邮件在显示文字后补充目标地址，同址文字不重复。
- 预览显示链接文字及完整目标，可选择复制；预览和编辑页不跳转，不会自动访问目标。脚本、事件和外部图片限制保持生效。

## 地址与兼容边界

仅允许完整的 `http://`、`https://` 或单邮箱 `mailto:` 地址；拒绝危险协议、相对地址、控制字符及带账号密码的网址，不猜测协议。URL 中的中文和查询参数可能显示为标准百分号编码，目标含义不变。

本版无需数据迁移：SQLite schema 仍为 5，模板交换格式仍为 1，既有应用标识、数据目录、账号、发送记录、冷却和排除规则保持不变。旧版本会清除文本链接；已经被旧版删除的网址无法恢复，含链接模板请用 v1.0.1 或更新版本编辑和交换。

## 使用与升级

Windows 10/11 x64：[下载单个 EXE](https://github.com/ahuiyuchuan/batch-send-email/releases/download/v1.0.1/Batch-Send-Email-v1.0.1-Windows-x64.exe)。系统需 WebView2 Runtime；完全退出旧版后运行新版，GitHub 自动生成的 Source code 归档不是可执行程序。

升级前建议退出并备份整个 `%LOCALAPPDATA%/com.ahui.qq-group-exporter/` 数据目录。回退到 v1.0.0 无需降低 schema，但旧版编辑含链接的内容会丢失链接；如需完整恢复升级前状态，退出程序并恢复原备份。
